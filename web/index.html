Search report agent

Explains how each keyword category performed and how it moved the market-level numbers. Code does every calculation; the agent only writes about results it fetched with tools; nothing reaches the report until a person approves it.

1Dashboard data

Upload the dashboard screenshots: the market view with no keyword category selected, plus one per category. The agent reads the numbers into the table below, then code cross-checks them. You can also type values in or import a CSV.

CSV format






  
2Data checks

  
Before any AI runs, code checks that the categories add up to the market total, this period and the previous period. Previous-period values are rebuilt from the % changes, so gaps under 2% are treated as rounding.

  






  
3Calculations

  
Share of the market change coming from each category. For volume metrics it’s each category’s change divided by the market change. For rates and CPAs, each category’s effect splits into its own rate moving (rate) and its share of volume moving (mix).

  






  
4Draft commentary

  
The agent works through seven calculation tools, decides what to investigate, and writes the four-part analysis: scale and efficiency, category roles, search funnel, and recommendations. Category roles are assigned by code, not by the agent.
